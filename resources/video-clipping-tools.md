# Video clipping tools — research shortlist

These are third-party GitHub repositories to evaluate for a short-form video workflow. Listing them here does **not** install their code or establish that they are Claude skills. Review each project's README, license, dependencies, security, and usage rights before running it.

| Project | Repository | Description from shared screenshot |
| --- | --- | --- |
| OpenShorts | https://github.com/mutonby/openshorts | Long video in, viral 9:16 shorts out |
| AutoClip | https://github.com/artbyjazi/autoclip | Local-first AI clipper, fully offline |
| NeonClipping | https://github.com/iamajmeena/neonclipping | Paste a link, captioned clips in ~2 min |

## Proposed evaluation

1. Check whether the project is maintained and licensed for intended use.
2. Check installation instructions, system requirements, and any API costs.
3. Test only with footage you own or are authorized to use.
4. Compare time to produce one usable vertical clip, subtitle quality, and editing flexibility.
5. Select one tool for the first Content Rewards experiment after confirming campaign rules.
